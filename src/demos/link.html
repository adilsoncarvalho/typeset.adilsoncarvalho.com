1 · Link

The link colour inherits from the surrounding text — a link is not blue here, only underlined — and the underline skips descenders rather than cutting through them.

The full argument runs on the project's own site, at example.org/measure.

2 · Printed URL

Paper has no hover and no click, so an external link's own URL is spelled out after the link text — in parentheses, mono, muted, one size down. Internal anchors and mailto: links are left alone; both already read fine as they are.

The essay itself is online, at the measure of a line.

Printed, this becomes: the measure of a line (https://example.org/on-the-measure) — a reader holding paper still has a way to find it.

3 · Link — URL suppressed

An opt-out for a link whose URL would be noise in print: a tracking parameter, a shortened redirect, or one the surrounding sentence already gives.

Corrections go to the correction form, whose address is a tracking redirect nobody should copy by hand.

Printed, this stays: the correction form — no parenthetical follows it.

1 · Heading 1 — document title

24pt sans at a light weight, tracked tighter than body text. It opens flush with the top of the page — no space above it, since nothing on the page comes before it.

The Elements

Body text follows immediately, at the ordinary rhythm — a heading is never the last thing on a page, and never alone.

2 · Heading 2 — section

A section heading also sets the page's own running head, so a reader mid-chapter can see which section they are in without turning back to find it.

Composition

A section opens here, and from this point the running head at the top of the page reads "Composition" until the next one changes it.

3 · Heading 3 — subsection

Smaller again, and still bold sans — clearly subordinate to the section above it, without needing a different colour or register to say so.

The measure

A subsection narrows the topic without opening a new run in the running head.

4 · Heading 4

The last level where size alone still carries the hierarchy — one step above body text, and the last one worth spending a size change on.

Choosing a ratio

Fourth level: still sans, still bold, one size larger than the paragraph beneath it.

5 · Heading 5

No size change from body — the register carries the level instead. Serif, small caps, tracked wider, so the eye reads it as a heading without the page gaining another size step.

On old-style figures

Fifth level: serif small caps at exactly the body size around it.

6 · Heading 6

One register further down: serif italic, still at body size — the quietest heading the scale offers, for a level that barely needs announcing.

A closing remark

Sixth level: serif italic, the same size as the text it introduces.

7 · Run-in heading

The heading shares the first line of its own paragraph, marked off by a muted mid dot — for a dense report where a full heading line costs more vertical space than the point is worth.

Run-in

a heading that shares the first line of its paragraph, which saves vertical space in a dense report.

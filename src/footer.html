typeset — Adilson Carvalho. spec.json is normative. The CSS and Typst panels are read out of typeset.css and typeset.typ at page load, so a panel cannot drift from the file it quotes.

Adding an engine means adding an implementation that hits the values in spec.json and a marker pair so this page can quote it. If an implementation and the spec disagree, the spec is right and the implementation is broken.

typeset

A typographic specification for printed documents — essays, letters, reports. Anything destined for paper or a PDF.

Each section below shows what an element must look like, the normative values it must hit, and the same values expressed in two engines. The specification is the source of truth; CSS and Typst are conformant implementations of it, not the definition. Point an engine — or an AI wiring one up — at this page and the output should match.

Raw files, for a machine

  • spec.json — the normative source. every value, every length absolute.
  • SPEC.md — the same thing as prose, generated from spec.json. Paste this into a model's context.
  • llms.txt — what to read first, and in what order.

Running a snippet

Every HTML pane below is a fragment. To run one on its own: link typeset.css, load the three families from fonts/, and wrap the fragment in an element carrying class="typeset" — every rule in the stylesheet is scoped under that class, so nothing outside it is touched. Bind every face, not one per family: the stylesheet asks the sans for 300, 600 and 700 and the serif for its italic and its semibold, and a family declared once with no font-weight and no font-style leaves the browser to slant and smear that single file into all of them. The essay is the same thing as a whole document.

Every Typst pane below assumes typeset.typ sits beside the document and has been imported and shown once, above the snippet. A snippet that opens with its own #show: typeset.with(…), or with a template that sets a page of its own such as #show: two-column.with(…) or #show: letter-page, replaces the second line rather than nesting under it — both set the page, and a page cannot be set inside a container.

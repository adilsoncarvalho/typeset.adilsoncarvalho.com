Raw files, for a machine

  • spec.json — the normative source. Every length absolute.
  • SPEC.md — the same thing as prose, generated from spec.json. Paste this into a model's context.
  • llms.txt — what to read first, and in what order.

Downloads

  • typeset-typst.zip — the Typst implementation, all three example documents and the three spec families. Typst cannot fetch a font from a URL, so a bundle is the only way to hand it over complete.
  • typeset-letter.iatemplate.zip — the iA Writer letter template, carrying typeset.css and every font face it binds.
  • typeset-css.zip — the stylesheet and the three spec families with their licences — what a template consumes, and what to self-host for a document you send.

typeset — Adilson Carvalho. spec.json is normative; CSS and Typst are conformant implementations of it, not the definition. If an implementation and the specification disagree, the specification is right.
